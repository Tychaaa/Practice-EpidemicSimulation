# Epidemic Simulation

Имитационная модель распространения эпидемии в замкнутой популяции.
Агентный подход: каждый человек — самостоятельный объект со своим
состоянием и перемещением, эпидемия возникает как результат их
взаимодействий.

## Возможности

- Настройка параметров модели через слайдеры: численность популяции,
  вероятность заражения, длительность болезни, скорость перемещения
- Визуализация состояний агентов в реальном времени
- График динамики заражений, обновляемый по ходу симуляции
- Главное меню и переключение экранов

## Стек

C#, .NET, MonoGame

## Структура

- `Simulation.cs` — логика модели и шаг симуляции
- `Person.cs` — агент: состояние, перемещение, заражение
- `InfectionGraph.cs` — построение графика динамики
- `MainMenu.cs`, `Slider.cs` — интерфейс и элементы управления
- `IScreen.cs` — абстракция экрана приложения

## Запуск

1. Установить .NET SDK и MonoGame
2. `dotnet run`
